# Dead Man's Wheel

A roulette roguelite. Eight nights in a saloon at the edge of nowhere. Every night the tab gets bigger and so does the wheel. Pay by closing time or you never leave.

**Play:** https://tdcrowell04.github.io/dead-mans-wheel/

This is a playtest build. Your name and how each run goes (bets, purchases, results) are sent to the developer to help balance the game. Your progress saves on your own device.
